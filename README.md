# AI двойник на ръководителя

Live Copilot (подсказки на живо в онлайн срещи), а по-късно и автономен двойник на ръководителя.
Проектът се строи с мисъл за B2B продукт: ядрото е едно, а методът, профилът на бизнеса и
форматът на изхода са сменяеми (Р21).

**Стратегия и решения:** [docs/strategy](docs/strategy) (последната версия на Word документа).

## Структура

| Папка | Какво съдържа |
|---|---|
| `packages/core` | Общи типове и интерфейси: среща, звук, транскрипт, разпознаване на говор, проверка за регион в ЕС, метрики (WER, закъснение), обработка на PCM |
| `packages/stt-whisper` | Локален Whisper (transformers.js) зад `SpeechToTextProvider`, с разделяне на изказвания по паузите |
| `packages/knowledge` | Пакети със знания: схема, проверка и разпознаване на споменати модели в разговора |
| `knowledge-packs/` | Данните на пакетите (JSON), напр. `zara-robotics`. Виж [описанието](knowledge-packs/README.md) |
| `tools/stt-bench` | Измерване на доставчиците за говор. Резултати: [docs/stt-benchmarks.md](docs/stt-benchmarks.md) |
| `apps/extension` | Chrome разширението за Google Meet: адаптер за Meet и панел (Фаза 1.0, скелет). Виж [инструкциите за зареждане](apps/extension/README.md) |
| `tools/strategy-doc` | Генератор на Word документа със стратегията |
| `docs/strategy` | Версиите на архитектурната стратегия |

## Команди

Изисква Node.js 22 или по-нов.

```bash
npm install
```

```bash
npm test
```

```bash
npm run typecheck
```

```bash
npm run build:extension
```

## Правила за сигурност

- API ключове и пароли се въвеждат само в локален `.env` файл и **никога** не влизат в git.
- Записи и транскрипти от реални разговори съдържат лични данни. Пазят се само локално в `data/` или `recordings/`, които git игнорира.
- Всички облачни доставчици трябва да обработват данните в ЕС (Р22). Кодът проверява това с `assertEuRegion`.
