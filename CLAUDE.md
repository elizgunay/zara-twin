# Указания за Claude

## Проектът

AI двойник на ръководител: първо Live Copilot за Google Meet (подсказки на живо), после автономен
двойник. Пилотът е за бизнеса Zara Robotics (дистрибутор на роботи Keenon). Целта е комерсиален
B2B продукт, затова ядрото не съдържа нищо специфично за конкретен клиент.

Решенията са номерирани (Р1, Р2, …) и записани в последната версия на `docs/strategy/*.docx`.
Генераторът е `tools/strategy-doc/build.js`. При нови решения се прави нова версия на документа,
старите не се презаписват.

## Как работим

- Общуването с потребителя е на български.
- Работим фаза по фаза и стъпка по стъпка. Без големи готови решения наведнъж.
- При всяка стъпка: рискове, алтернативи и уточняващи въпроси.
- Claude е архитектът и разработчикът. Собственикът създава акаунтите, въвежда ключовете лично и тества в реални срещи.

## Технически правила

- TypeScript навсякъде (Р15), npm workspaces. `packages/core` се ползва директно от изходния код, без build стъпка.
- Платформата за срещи е скрита зад `MeetingAdapter`, а доставчикът на говор зад `SpeechToTextProvider`.
- Само браузъри на база Chromium (Р18).
- Данните се обработват само в ЕС (Р22): всеки облачен доставчик минава през `assertEuRegion`.
- Бюджетът засега е нула (Р17): само безплатни нива и локални решения. Всяка платена услуга изисква изрично одобрение.
- Никакви ключове, записи или транскрипти в git (виж `.gitignore`).
- Коментарите в кода са на български, имената в кода на английски.

## Команди

- `npm test` пуска тестовете (Vitest).
- `npm run typecheck` проверява типовете.
- `npm run build:extension` изгражда разширението в `apps/extension/dist` (esbuild, IIFE).
- Визуална проверка на панела без Meet: страница, която подменя `window.chrome`, зарежда `dist/content.js` и се снима с `msedge --headless=new --screenshot`.
