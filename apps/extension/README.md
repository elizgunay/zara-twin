# Chrome разширение (Live Copilot)

Manifest V3 разширение за Google Meet. Работи във всички браузъри на база Chromium (Р18).

## Какво прави сега (скелет)

- Натискане на иконата на разширението в таб на Meet показва или скрива панела „Zara Copilot“.
- Панелът показва кода на срещата и напомняне участниците да бъдат уведомени.
- Подготвен е за показване на транскрипт (`appendSegment`), но прихващането на звук още липсва.

## Как да го заредите в Chrome или Edge

1. Изградете го от корена на проекта:

   ```bash
   npm run build:extension
   ```

2. Отворете `chrome://extensions` (в Edge: `edge://extensions`).
3. Включете **Developer mode** (Режим за разработчици).
4. Натиснете **Load unpacked** и изберете папката `apps/extension/dist`.
5. Отворете среща в Google Meet (или презаредете вече отворен таб) и натиснете иконата на разширението.

След промяна в кода: изградете отново и натиснете бутона за презареждане на разширението в `chrome://extensions`.
