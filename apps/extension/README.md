# Chrome разширение (Live Copilot)

Предстои във Фаза 1.0: минимално разширение (Manifest V3) за Google Meet, което:

1. показва видимо уведомяване, че срещата се транскрибира;
2. прихваща поотделно звука от таба (отсрещната страна) и микрофона (собственика);
3. подава звука към избран `SpeechToTextProvider` от `@zara-twin/core`;
4. показва българския текст в панел върху прозореца на Meet;
5. записва закъснението за всеки сегмент за сравнението на доставчиците.

Работи във всички браузъри на база Chromium (Р18).
